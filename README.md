# 📊  Exploratory Data Analysis (EDA)

## 🔍 Objective:
Perform Exploratory Data Analysis (EDA) on the Titanic dataset (tested.csv) to uncover patterns, trends, and anomalies using Python (Pandas, Seaborn, Matplotlib).

---

## 📁 Files Included:
- `tested.csv`: Input dataset
- `EDA_Task5_Report.pdf`: Final report with visualizations and findings
- `Task5_EDA.ipynb`: Jupyter notebook with complete code (to be added by you)
- `README.md`: This file

---

## 📌 Key Analysis Steps:
1. Data Overview – `.info()`, `.describe()`
2. Missing Values – Heatmap visualization
3. Univariate Analysis – Histograms, boxplots
4. Bivariate Analysis – Correlation heatmap, scatterplots
5. Multivariate Analysis – Pairplots
6. Observations & Insights

---

## 📈 Key Observations:
- Outliers observed in `Fare` and `Age`
- Missing data in columns like `Age`, `Cabin`
- Most passengers were in Pclass 3 and embarked from port 'S'
- Moderate positive correlation between `Fare` and `Survival`
